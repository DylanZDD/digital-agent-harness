# Code Review Skill

当用户要求审查代码时,按以下流程执行:

1. **通读**整体结构,确认代码意图。
2. **正确性**:边界条件、空值、并发、资源释放、异常路径。
3. **可读性**:命名、抽象层次、重复代码、注释密度。
4. **安全性**:输入校验、注入、权限、敏感信息泄露。
5. **性能**:不必要的 O(n²)、N+1 查询、重复计算、内存峰值。

输出格式:
- 用 `文件名:行号` 引用具体位置。
- 每条问题给出:严重程度(🔴 高 / 🟡 中 / 🟢 低)+ 问题 + 建议改法。
- 末尾给一句话总体结论。
